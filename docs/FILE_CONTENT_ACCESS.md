# FileBuddy 文件内容读取说明

## 当前能力

FileBuddy 已支持在用户授权的 `/workspace` 目录内：

- 列出文件
- 获取文件信息
- 读取文本文件
- 分段读取文本文件
- 搜索文本内容
- 在读写权限下写入文本文件

## Office 文件说明

`.docx`、`.xlsx`、`.pptx` 等 Office 文件本质上是 ZIP 二进制容器，不能直接当作普通文本读取。

如果直接调用文本读取接口，可能看到类似下面的内容：

```text
PK\x03\x04...
```

这不是文件正文，而是压缩包的二进制字节。

## 正确处理方式

完整读取 Office 文件应采用以下流程：

```text
读取文件信息
    ↓
按分块传输二进制内容
    ↓
解压 Office ZIP 容器
    ↓
解析 document.xml / sharedStrings.xml 等 XML
    ↓
提取正文、表格或幻灯片内容
```

## 安全规则

1. 只访问 `/workspace` 下的路径。
2. 读取大文件时必须分块，不要一次性载入整个文件。
3. 修改文件前先读取最新版本。
4. 不要把二进制内容直接当作 UTF-8 文本展示。
5. 不要输出真实磁盘路径、登录令牌、API Key 或服务器密钥。

## Agent 行为建议

当用户要求查看 Word、Excel 或 PowerPoint 内容时：

1. 先确认文件扩展名和大小。
2. 如果当前没有 Office 解析工具，明确说明只能读取原始二进制，不能保证正文可读。
3. 不要把完整二进制内容直接放入对话上下文。
4. 等待或调用专用 Office 解析能力后，再返回结构化正文。
